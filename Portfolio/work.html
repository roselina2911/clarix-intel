01
Healthcare Enterprise

Healthcare AI Service Recovery Agent

AI Agent Full-Stack Web App Data Pipeline
Stack React · TypeScript · Node.js · SQLite · Anthropic Claude API · REST APIs

The problem

A large healthcare company needed a way to automatically analyse AI-generated clinical outcomes and generate recovery action plans for cases where the expected outcome wasn't met. The process was entirely manual — taking senior staff hours every week.

What we built

A full-stack AI service recovery agent: a React + TypeScript + Node.js web application with an integrated Anthropic Claude AI backend. The system ingested structured outcome data, analysed deviations against benchmarks, generated recovery action plans, and surfaced them in a real-time dashboard for clinical operations teams.

The outcome

  • Recovery analysis time reduced from hours to under 2 minutes per case
  • Full audit trail for every AI-generated recommendation
  • Zero manual data entry in the core workflow
  • Deployed with mock source system integration, ready for production API connection
02
Diagnostic Healthcare

WhatsApp Patient Query Bot

Intelligent Chatbot WhatsApp Integration
Stack WhatsApp Business API · Python · LangChain · ChromaDB · FastAPI · Twilio

The problem

A diagnostic centre chain was receiving 400+ WhatsApp messages daily — appointment bookings, report status queries, test pricing questions. Staff were spending 3–4 hours daily on responses that were nearly identical.

What we built

A WhatsApp Business API chatbot powered by an LLM backend with a RAG knowledge base containing the centre's service catalogue, pricing, and appointment logic. The bot handled booking, confirmation, reminders, and report dispatch automatically. Complex queries triggered a clean handoff to a human agent with full context pre-loaded.

The outcome

  • 78% of daily queries resolved without human involvement
  • Staff time on WhatsApp reduced from 3.5 hrs/day to under 45 minutes
  • Appointment no-shows reduced by 34% through automated reminders
  • Deployed within 3 weeks of project start
03
Fintech SaaS

B2B SaaS Data Integration Pipeline

Data Pipeline Enterprise Integration Dashboard
Stack Python · Airflow · PostgreSQL · React · Node.js · Salesforce API · Stripe API

The problem

A B2B SaaS company's enterprise clients were using 5 different data sources (Salesforce, internal PostgreSQL, Google Sheets, an ERP, and a payments API). There was no unified view. The ops team spent two days every week manually compiling a single consolidated report.

What we built

An automated data ingestion and transformation pipeline that pulled from all 5 sources on a scheduled cadence, normalised the data into a clean PostgreSQL warehouse, and surfaced it in a custom React dashboard with role-based access for different stakeholder views. Included automated email reports generated every Monday morning.

The outcome

  • 2-day manual process eliminated entirely
  • Real-time unified data view available 24/7
  • 6 stakeholder report formats automated
  • Pipeline runs every 4 hours with failure alerting
